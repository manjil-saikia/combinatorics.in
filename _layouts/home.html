A note on how the courses fit together

MAT 631 is a sequel to MAT 315/515 Combinatorial Enumeration, and MAT 730 is a sequel to MAT 631. In each case the earlier course is recalled rather than assumed, so you can enter at any point. Different iterations of the same course will contain new materials.
